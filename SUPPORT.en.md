# Support

> Spanish version: [SUPPORT.md](SUPPORT.md). The Spanish version is authoritative. In case of conflict, the Spanish version prevails.

## Support scope

Cardumen Deck is an open-source project maintained on a community-effort basis. Support is best effort and has no service-level agreement (SLA).

The project does not offer:

- commercial support;
- phone support;
- guaranteed response times;
- a bug bounty;
- indemnification;
- an availability commitment.

## Where to ask

- **Questions and general use:** repository discussions.
- **Reproducible bugs:** issue with steps, version, and environment.
- **Improvements:** proposal issue with the problem and use case.
- **Vulnerabilities:** GitHub Security Advisories, never a public issue.

## What to include in a report

- Cardumen Deck version.
- Windows version.
- WebView2 version.
- Steps to reproduce.
- Expected and observed behavior.
- Relevant logs without secrets, tokens, or personal data.
- Screenshots only if they do not expose sensitive information.

## Supported versions

The main branch and the latest `0.1.x` version receive fixes. Older versions may not receive support.

## Security

Do not publish vulnerabilities in public issues. See [SECURITY.en.md](SECURITY.en.md) for the private process.

## Real development use

Cardumen Deck is a local development tool. It is not a managed service or a production component. Support does not include operating services, recovering data, or managing credentials.
