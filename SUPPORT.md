# Soporte

> Versión en inglés: [SUPPORT.en.md](SUPPORT.en.md). La versión en español es la principal. En caso de conflicto, prevalece esta versión.

## Alcance del soporte

Cardumen Deck es un proyecto de código abierto mantenido con esfuerzo comunitario. El soporte es de mejor esfuerzo y no tiene un acuerdo de nivel de servicio (SLA).

No se ofrece:

- soporte comercial;
- soporte telefónico;
- tiempos de respuesta garantizados;
- programa de recompensas por errores;
- indemnización;
- compromiso de disponibilidad.

## Dónde consultar

- **Preguntas y uso general:** discusiones del repositorio.
- **Errores reproducibles:** incidencia con pasos, versión y entorno.
- **Mejoras:** incidencia de propuesta con el problema y el caso de uso.
- **Vulnerabilidades:** GitHub Security Advisories, nunca una incidencia pública.

## Qué incluir en un reporte

- Versión de Cardumen Deck.
- Versión de Windows.
- Versión de WebView2.
- Pasos para reproducir.
- Comportamiento esperado y comportamiento observado.
- Registros relevantes sin secretos, tokens ni datos personales.
- Capturas solo si no exponen información sensible.

## Versiones soportadas

La rama principal y la última versión `0.1.x` reciben correcciones. Las versiones anteriores pueden no recibir soporte.

## Seguridad

No publiques vulnerabilidades en incidencias públicas. Usa [SECURITY.md](SECURITY.md) para el proceso privado.

## Uso en desarrollo real

Cardumen Deck es una herramienta local para desarrollo. No es un servicio gestionado ni un componente de producción. El soporte no incluye la operación de servicios, la recuperación de datos ni la administración de credenciales.
